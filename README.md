# Spi_screen_rockpi4
Эээ ну эта инструкция предназначена для тех кто купил  spi экран для rock pi 4 и не смог подключить
так ну сначала нужно отобрать spi1 у флеш памяти дописав ниже оверлея параметр и из оверлея убрать rockchip-rk3399-spi-spidev из overlays= в /boot/armbianEnv.txt если он там был остальные оверлеи можно оставить далее скачать оверлей и закинуть его куданибудь я в деректорию рута кидал ибо у меня на тот момент небыло другого юзера вот этой командой добавляется пользовательские оверлеи в армбиан:"armbian-add-overlay /root/rockpi4a-ili9486-fbtft.dts" ну путь может быть иным после нее вам предложат перезагрузится(кстати вот насчет этого оверлея я настоятельно рекомендую открыть этот файлик и изменить там частоту с 16000000 до 8000000 чтобы избежать мешанины из пиксилей ноо ценой снижения частоты обновления дисплея, в целом можно и 16000000 оставить смотрите сами) дальше проверить стал ли экран серым если нет тоо выключить дрм драйвер временно "echo spi1.0 | sudo tee /sys/bus/spi/drivers/ili9486/unbind
echo spi1.0 | sudo tee /sys/bus/spi/drivers/fb_ili9486/bind" если после этого экран стал серым тоо осталось его не загружать(тот драйвер)" sudo tee /etc/modprobe.d/disable-ili9486-drm.conf >/dev/null <<'EOF'
blacklist ili9486
install ili9486 /bin/false
EOF
" ну или можно вручную создать этот файлик и в него дописать 2е строки эти, дальше:
"sudo update-initramfs -u
sudo reboot
"
 ну и все теперь экран готов к работе ну и чтобы вывести на него 1ую  tty "con2fbmap 1 1" ну это все при условии что этот экран подключен с одним  hdmi ну тоесть определянтся не как  fb0 а как  fb1 ну а дальше думаю разберетесь
